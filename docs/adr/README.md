# Architecture Decision Records

Short records of significant, non-obvious engineering decisions — written when a decision is
actually made or, for decisions already made silently in past sessions, once the reasoning behind
them needs to be discoverable rather than re-derived from scratch. Not a retroactive history of
every choice in this project — only ones where the "why" isn't obvious from reading the code
alone, and where getting it wrong again would cost real time.

Format: numbered, one file per decision, `NNNN-short-title.md`.
